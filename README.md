# Threshold Bureau

Threshold Bureau es una identidad ficticia de consultoría enfocada en diseño instruccional, sistemas de aprendizaje y desarrollo de experiencias digitales.

El proyecto nace como parte de mis actividades académicas de Desarrollo Full Stack para la Universidad TEC Milenio y está diseñado para funcionar también como un espacio donde documentar y presentar proyectos relacionados con mi experiencia profesional personal.

## Relación con Diario Muerto

Threshold Bureau está pensado como una futura sección de **Diario Muerto**, mi proyecto web personal.

Diario Muerto funciona como un registro de mi proceso de aprendizaje y desarrollo creativo. Su propósito es documentar proyectos, ejercicios y experiencias relacionadas con áreas como desarrollo de software, dibujo, pintura, escritura y, eventualmente, viajes.

Threshold Bureau representa la rama profesional de esa misma idea.

Mientras Diario Muerto documenta mi proceso creativo y personal, Threshold Bureau reúne proyectos relacionados con mi experiencia laboral, diseño instruccional, sistemas de aprendizaje, análisis de información y desarrollo de herramientas digitales.

La intención es que ambos espacios formen parte de un mismo sitio personal: un archivo del proceso creativo humano y, al mismo tiempo, una puerta hacia ejemplos concretos de mi experiencia profesional.

### TB-001 — Public Interface

TB-001 es la primera implementación de Threshold Bureau.

Este proyecto fue desarrollado como parte de una actividad académica enfocada en los fundamentos del desarrollo web y utiliza:

- HTML semántico
- CSS
- Diseño responsivo
- Accesibilidad web
- Formularios HTML

Además de cumplir con los requerimientos académicos, TB-001 funciona como la base visual y estructural de los futuros proyectos de Threshold Bureau.

### Propósito de aprendizaje

El código de este proyecto se mantiene deliberadamente sencillo.

El objetivo no es utilizar las herramientas más avanzadas disponibles, sino comprender conscientemente los fundamentos detrás de cada elemento implementado y construir una base que pueda evolucionar conforme avance mi aprendizaje en desarrollo full stack.
