# Threshold Bureau

Threshold Bureau es una identidad ficticia de consultoría enfocada en diseño instruccional, sistemas de aprendizaje y desarrollo de experiencias digitales.

El proyecto nace como parte de mis actividades académicas de Desarrollo Full Stack para Universidad Tecmilenio y, al mismo tiempo, como un espacio experimental donde documentar y presentar proyectos relacionados con mi desarrollo profesional.

## Relación con Diario Muerto

Threshold Bureau está pensado como una futura sección de **Diario Muerto**, mi proyecto web personal.

Diario Muerto funciona como un registro de mi proceso de aprendizaje y desarrollo creativo. Su propósito es documentar proyectos, ejercicios y experiencias relacionadas con áreas como desarrollo de software, dibujo, pintura, escritura y, eventualmente, viajes.

Threshold Bureau representa la rama profesional de esa misma idea.

Mientras Diario Muerto documenta mi proceso creativo y personal, Threshold Bureau reúne proyectos relacionados con mi experiencia laboral, diseño instruccional, sistemas de aprendizaje, análisis de información y desarrollo de herramientas digitales.

La intención es que ambos espacios formen parte de un mismo sitio personal: un archivo del proceso creativo humano y, al mismo tiempo, una puerta hacia ejemplos concretos de mi experiencia profesional.

## TB-001 — Public Interface

TB-001 es la primera implementación de Threshold Bureau.

Este proyecto fue desarrollado como parte de una actividad académica enfocada en los fundamentos del desarrollo web y utiliza:

- HTML semántico
- CSS
- Diseño responsivo
- Accesibilidad web
- Formularios HTML

Además de cumplir con los requerimientos académicos, TB-001 funciona como la base visual y estructural de los futuros proyectos de Threshold Bureau.

## Objetivo de la primera iteración

La primera versión de Threshold Bureau fue planteada como una interfaz pública sencilla y funcional.

El objetivo principal fue construir una página clara, semánticamente organizada y responsiva que pudiera cumplir con los requerimientos de la actividad sin introducir herramientas o estructuras innecesariamente complejas.

La interfaz prioriza:

- una jerarquía visual clara;
- alto contraste y legibilidad;
- uso amplio de espacio negativo;
- navegación sencilla;
- estructura semántica;
- adaptación a dispositivos móviles y de escritorio;
- una identidad visual coherente con el concepto de Threshold Bureau.

Esta primera etapa funciona como punto de partida sobre el cual se desarrollarán interfaces progresivamente más complejas en futuras actividades.

## Dirección visual de Threshold Bureau

Desde TB-001, Threshold Bureau fue concebido con la intención de desarrollar una identidad visual inspirada en interfaces institucionales, sistemas de archivo y diseño editorial minimalista.

Una de las principales referencias conceptuales es el trabajo visual desarrollado por **Remedy Entertainment** en la serie **Control**, cuya interfaz considero un ejemplo particularmente completo de cómo tipografía, composición, movimiento, espacio negativo y diseño de información pueden integrarse dentro de una misma experiencia.

En lugar de intentar reproducir esta estética de forma inmediata, TB-001 establece únicamente sus fundamentos:

- superficies oscuras;
- tipografía de alto contraste;
- composición minimalista;
- estructura modular;
- énfasis en la legibilidad;
- uso limitado de color como elemento de jerarquía.

La intención es que cada actividad posterior funcione como una nueva iteración del sistema, incorporando gradualmente más elementos de esta dirección visual conforme también aumente la complejidad técnica de los proyectos.

De esta forma, la evolución gráfica de Threshold Bureau acompaña la evolución de mi aprendizaje en desarrollo full stack.

## Relación con la evaluación académica

La estructura de TB-001 fue desarrollada considerando los principales criterios de evaluación de la actividad:

- organización semántica del HTML;
- funcionamiento y validación del formulario;
- diseño y estilización mediante CSS;
- diseño responsivo;
- accesibilidad y experiencia de usuario;
- creatividad y coherencia visual.

La identidad visual de Threshold Bureau permite abordar estos requerimientos dentro de un concepto propio, evitando tratar la actividad únicamente como un ejercicio aislado.

## Propósito de aprendizaje

El código de este proyecto se mantiene deliberadamente sencillo.

El objetivo no es utilizar las herramientas más avanzadas disponibles, sino aplicar correctamente los fundamentos solicitados por la actividad y construir una base que pueda evolucionar conforme avance mi aprendizaje en desarrollo full stack.

Los conceptos introducidos en estas actividades académicas se utilizarán posteriormente como referencia para proyectos personales de mayor profundidad, donde podrán ser estudiados, ampliados y aplicados con mayor detalle.
